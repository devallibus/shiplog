# Resume

Inspect the current branch, `git status`, and recent commits. Find the linked issue or PR from the branch, existing links, or project context. Do not assume that only one branch-name format is valid or switch worktrees merely because another name matches.

Read the current summary first. Follow source links when a decision, preference, or reference is unclear. Check the actual changes, PR head, checks, and unresolved findings before choosing the next step. Stale summary text does not override code or current evidence. If `.shiplog/logging.md` sets `logging: quiet`, read [references/quiet-logging.md](references/quiet-logging.md) and read the current summary at the log location.

Continue with the next unfinished action. Update the summary only when there is new state to record. Capture new discussion through [timeline.md](timeline.md). Do not post a routine session-resume comment or open a routing prompt when routing is off.

# Handle a discovery

Fix a small in-scope problem inline when that is part of the authorized work. Record it at the next checkpoint if its reason, failed approach, or remaining risk matters for future work.

If the discovery changes scope or needs later work, preserve the discussion and link a follow-up issue. A prerequisite may need a separate branch or PR; use the project's existing dependency workflow. Do not create a stacked PR merely to record an observation.

Update the current summary when the discovery changes a decision, blocker, or next action. Follow [references/records.md](references/records.md) and keep human wording intact.
